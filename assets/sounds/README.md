# 🎵 Audio Assets - Sons du Jeu 2048

Dossier contenant tous les fichiers audio du jeu.

---

## 📁 Fichiers Requis

### Sons d'événements (5 fichiers .ogg)

| Fichier | Durée | Cas d'usage | Caractéristiques |
|---------|-------|-----------|-------------------|
| `move.ogg` | 0.1-0.3s | Chaque coup du joueur | Clac sec, léger, non-intrusif |
| `merge.ogg` | 0.3-0.7s | Fusion de deux tuiles | Pop satisfaisant, gratifiant |
| `game_over.ogg` | 1-2s | Défaite (aucun coup) | Bruit négatif, game over |
| `win.ogg` | 2-3s | Victoire (2048 atteint) | Fanfare, célébration |
| `background.ogg` | 30s-2min | Musique en boucle | Relaxante, ambiance, peut boucler |
