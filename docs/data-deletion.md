# Demande de suppression des données — Mergestorm 2048

Si vous souhaitez que vos données locales soient supprimées, vous avez deux options :

1. Supprimer directement depuis l'application : ouvrez **Paramètres > Réinitialiser le jeu** pour effacer les scores, paramètres et données de la boutique.

2. Nous contacter pour une suppression à distance : envoyez un message à **support@benjaminaubry.com** en précisant :
   - Le nom de l'app : *Mergestorm 2048*
   - L'identifiant de l'appareil (facultatif) : pour nous aider à localiser les données
   - Votre demande : *Suppression des données personnelles / suppression des données locales*

Remarque : l'application stocke uniquement des données localement sur votre appareil (scores, paramètres, inventaire). Aucune donnée personnelle n'est envoyée à un serveur par défaut. En cas de demande par email, nous répondrons sous 7 jours ouvrés avec confirmation de suppression ou instructions supplémentaires.
